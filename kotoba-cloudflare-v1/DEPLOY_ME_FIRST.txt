KOTOBA — DEPLOY LÊN CLOUDFLARE (WINDOWS)
========================================

1) Giải nén folder này.
2) Mở folder bằng VS Code.
3) Chọn Terminal -> New Terminal.
4) Copy đúng 1 lệnh sau và Enter:

powershell -ExecutionPolicy Bypass -File .\scripts\deploy-first-time.ps1

5) Khi trình duyệt Cloudflare mở ra -> bấm Allow / Authorize.
6) Quay lại Terminal và chờ chạy xong.
7) Cuối cùng Terminal sẽ cho URL dạng:

https://kotoba.xxxxx.workers.dev
